# Alireza Azimi — Interactive Resume

An interactive Persian-language resume built with HTML, CSS, and JavaScript.

## Overview

This project presents my professional background, financial market experience, trading system development, software projects, technical skills, and interactive experiments in a single web page.

## Features

- Responsive dark-themed interface
- Animated visual elements and interactive navigation
- Financial markets and trading systems profile
- Software development and personal projects
- Interactive lab featuring visual and startup evaluation experiments
- Ambient audio controls
- Print-friendly styling

## Technologies

- HTML5
- CSS3
- JavaScript

## Live Demo

The live version will be available through GitHub Pages:

[View Interactive Resume](https://YOUR-USERNAME.github.io/alireza-azimi-resume/)

Replace `YOUR-USERNAME` with your GitHub username.

## Run Locally

1. Download or clone this repository.
2. Keep `index.html` and the MP3 audio file in the same directory.
3. Open `index.html` in a modern web browser.

The resume does not require a build process or package installation.
